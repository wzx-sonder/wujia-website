# 武汉悟佳教育咨询有限公司官网

静态多页面官网，无运行时框架或第三方构建依赖。使用 Node.js 生成 HTML，`dist/` 为完整发布目录。

线上地址：[悟佳官网](https://wujia-ai.g1304458637.chatgpt.site/)。

## 构建与检查

```sh
npm run build
npm run check
```

构建保留 `dist/assets/` 中已确认的图片与视频，生成十个页面及共享 CSS / JavaScript。修改对应内容源后重新构建，不要手工修改生成的 HTML。将 `dist/` 部署在域名根目录，静态服务器应支持文件夹中的 `index.html`。

本地预览可在构建后运行 `python -m http.server 8000 --directory dist`，然后打开 `http://localhost:8000/`。也可以使用其他静态文件服务器。

本仓库保存官网源码与发布文件，推送 GitHub 不会自动更新现有 Sites 官网。

## 文件维护

- `scripts/build.mjs`：共享页头、页面外壳、栏目开篇、产品卡片和详情模板；输出到 `dist/`。
- `scripts/check.mjs`：检查页面标题、ID、ARIA 关联、链接、锚点、媒体与旧链接目标。
- `src/products.mjs`：产品摘要、版本清单与旧首页锚点映射。
- `src/navigation.mjs`：现行栏目与产品入口的标准文案和地址，供页头、页脚、卡片与正文标签共享。
- `src/sections/`：已确认的公司、AI、共创、方法、愿景、联系等内容。
- `src/products/`：三个产品的功能说明与适用范围。
- `src/partials/`：共享页脚、视频弹窗、回顶按钮。
- `src/shared/content.js`：已确认的外部产品入口与五支视频配置。
- `src/shared/app.js`：下拉菜单、视频弹窗、版本选择与页内滚动。
- `src/shared/styles.css`：原官网视觉样式；`multipage.css` 补充多页面和响应式布局。
- `dist/assets/`：已确认的本地图片、视频与品牌背景，作为构建保留资产。

## 导航与交互

主导航包含首页及五个栏目，文字直接进入对应页面，仅产品菜单保留独立下拉按钮。内部链接使用当前标签页的原生页面导航；外部产品入口打开新标签页。产品详情提供面包屑及返回列表入口。首页的旧锚点地址自动替换到对应页面，避免产生无效返回记录。

同一用途的入口使用同一文案和地址；每张产品概览卡片只有一个“产品名 + 详情”链接，标题和封面仅展示。合作方向是说明文字。栏目当前页在顶部和页脚以非交互选中项显示；产品详情中的“产品与项目”仍可返回列表。HUBU / KCode 快捷入口使用明确的版本参数。

正文使用新页面的显式路径，`{{label:入口名}}` 仅引用共享文案。旧锚点映射只兼容历史分享链接，不参与正文地址生成。“项目短片”进入合集，“播放宣传片”打开当前视频弹窗。

回到顶部与明确的页内链接沿用 550 毫秒滚动动画；新页面与历史导航保留浏览器行为。回顶按钮滚动时展开，停止 600 毫秒后缩为圆形，收缩动画为 280 毫秒；减少动态效果设置下省略动画。

各页面仅初始化实际存在的组件。媒体、样式和脚本使用根路径，适配三级页面直接打开与刷新。
